# Collection UX V5

Goal: make it impossible for a first-time customer to mistake the four homepage highlights for the full product range.

- Hero CTA now says **Shop all 82 products**.
- New high-visibility gateway states **82 products / 15 categories** and explains that homepage items are highlights only.
- Category block states **4 of 15** and shows product counts for the four popular categories.
- Featured area states **4 highlights / 82 total** and includes a large post-grid **Shop the collection** CTA.
- Catalogue heading clearly states the full 82-product / 15-category range.
- Mobile bottom navigation uses **Products** with an 82 badge instead of the more ambiguous Collection label.
- Existing favourites, quantity, enquiry, WhatsApp, PDF and cart features are preserved.
- Desktop/mobile menu Collection item also carries an **82** product-count badge.
