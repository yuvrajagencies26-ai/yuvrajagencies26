# Component integration

The original UI showcase components were adapted into the existing Madhan Crackers experience rather than copied as a separate demo.

- Tooltip icon pattern → WhatsApp / Call / Email quick-contact controls in the footer.
- Neumorphic button → secondary actions, price-list and filter controls.
- Animated green pill → branded WhatsApp header action.
- Leaf-burst animation → fireworks burst on primary celebration CTAs.
- Day/night toggle → existing persisted light/dark theme control.
- Glass blob card → hero/contact/enquiry premium card highlights.
- Neumorphic input → search, enquiry form, select and textarea states.
- Radio glider → functional All / Available / Saved quick filter on the catalogue.

Existing cart, wishlist, enquiry, printable PDF flow, navigation, product data, accessibility labels and responsive layout are preserved.
