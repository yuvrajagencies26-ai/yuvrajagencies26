# Cart + PDF Upgrade

## Cart improvements
- Search inside selected products
- Sort selected products by added order, name, category, or line amount
- Per-product quantity stepper, +1 box, save/unsave, view, and remove actions
- Add saved favourites to cart in one click
- Copy cart list and native share/fallback copy
- Unique product, total box, pending-rate, and estimated-total summary
- Continue shopping and scroll-to-details actions
- Responsive mobile cart layout

## PDF visibility
- Permanent PDF Price List control in the site header
- Floating PDF shortcut on every page
- Dedicated price-list PDF banner on enquiry page
- PDF access from cart summary
- High-visibility Print / Save enquiry as PDF button

All additions preserve the existing localStorage cart/favourites and WhatsApp enquiry flow.
