# Collection Cart UX V6

Collection page now carries the useful enquiry-cart controls without duplicating the full cart UI.

- Live selected-product count
- Total box count
- Estimated catalogue total + pending-rate indicator
- Review Enquiry CTA
- WhatsApp selected list
- Add saved products
- Copy product list
- Native Share / copy fallback
- PDF price-list shortcut
- Clear selection
- Product-card selected state + quick View Details / Review Enquiry links
- Mobile sticky enquiry tray above the bottom navigation

The catalogue's existing search, category filter, sort, availability filter, price filter, quantity controls and favourite system remain intact.
